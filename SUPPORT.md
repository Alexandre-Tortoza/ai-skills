# Support

`ai-skills` is currently pre-alpha. There is no supported production release yet.

## Bugs

Use the GitHub bug report form and include reproducible steps, environment details and safe diagnostic output. Do not include credentials, private skill content or other sensitive data.

## Feature and design proposals

Use the appropriate Feature Request, Technical Task or Skill/Knowledge Proposal Issue Form. Search existing issues first.

## Questions and design discussion

GitHub Discussions is the intended home for non-actionable usage/design conversations once enabled. Repository setup for Discussions and other community features is tracked by #66.

## Security

Do not report exploitable vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) and use GitHub's private security advisory flow.

## Releases

Only published GitHub releases described as supported should be treated as distributable versions. Source on `main` may be incomplete during pre-alpha development.
